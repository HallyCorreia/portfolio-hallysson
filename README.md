# Portfolio — Hallysson Correia

Site pessoal de Hallysson Correia: automação de processos, IA, infraestrutura e desenvolvimento web.

🔗 https://hallyssoncorreia.com

## Stack

React + TypeScript + Vite, Tailwind CSS e shadcn/ui.

## Como rodar

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/ (não versionado)
```

## Estrutura

- `src/sections/` — seções da página (Hero, About, Experience, Projects, Skills, Automation, Contact)
- `src/components/` — componentes de UI
- `public/` — imagens servidas estaticamente (preferir WebP, até ~200 KB)
